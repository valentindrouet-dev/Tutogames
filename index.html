SOURCE NON CONSTRUITE

Cette page est le fichier source de l'application, pas sa version construite. GitHub Pages publie donc la racine du depot au lieu du dossier dist/ produit par Vite.

Correctif : dans Settings › Pages du depot, mettre Source sur GitHub Actions au lieu de Deploy from a branch, puis relancer le workflow « Deployer sur GitHub Pages ».

En local, lancer npm run dev : ce message disparait des que l'application se monte.
